# Architektura naukowo-informatyczna

Syntetyczny opis repozytorium znajduje się w [ARCHITECTURE.md](../../ARCHITECTURE.md). Ten katalog dokumentuje **faktyczne** przepływy danych, granice narzędzi, odtwarzalność i archiwizację wyników. Nie jest zamiennikiem protokołu badania, SAP ani rejestru decyzji naukowych.

- [Przepływy danych](data-flow.md): pozyskanie, anonimizacja, przetwarzanie i odbiorcy.
- [Odtwarzalność](reproducibility.md): zamrożone SHA, aparatura, bibliografia, źródła TikZ, wyniki i walidacja.
- [Model zagrożeń](../security/threat-model.md): uprawnienia, dane uczestników i publikacja.
- [ADR](../adr/README.md): decyzje infrastrukturalne i architektoniczne.

Status szablonu: `NOT_IMPLEMENTED`. Gdy powstaje badanie, aktualizuj te pliki w tym samym PR co implementację. Nie wnioskuj o przeprowadzonych pomiarach na podstawie gotowości dokumentu.
