# Bezpieczeństwo i prywatność

Zgłoszenia bezpieczeństwa kieruj do właściciela projektu przez prywatny kanał kontaktu. Nie zgłaszaj publicznie danych uczestników, tokenów, haseł, list klientów, zastrzeżonych skal ani identyfikowalnych sygnałów fizjologicznych.

Publiczny kod i GitHub Pages nie są magazynem danych osobowych. Repozytoria prywatne również nie są domyślnym miejscem na dane uczestników. Dozwolone są jawne identyfikatory aparatury w kanonicznym prywatnym katalogu sprzętu, ale nie poświadczenia. Publikacja danych następuje po ocenie anonimizacji, zgód, RODO, licencji i miejsca przechowywania.
