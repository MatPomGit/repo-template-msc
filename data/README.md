# Dane

W tym folderze przechowuj wyłącznie bezpieczne metadane, deklaracje schematów i manifesty wersji zbiorów. `raw/`, `private/` i `processed-private/` są ignorowane przez Git. Nie commituj surowych danych uczestników, nagrań i danych zdrowotnych. Właściwy magazyn określa `research/data-management.md`.
